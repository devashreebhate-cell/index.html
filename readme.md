# Simple Arithmetic Calculator (Switch Case)

This is a basic calculator built using:

- HTML
- CSS
- JavaScript (Switch Case)

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division by zero handling
- Simple and clean design

## How to Run

1. Download all files:
   - index.html
   - scripts.js
   - style.css

2. Keep all files in the same folder.

3. Open `index.html` in your browser.
